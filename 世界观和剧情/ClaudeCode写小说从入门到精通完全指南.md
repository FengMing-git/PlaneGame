# Claude Code 写小说：从入门到精通完全指南

> **适合人群：** 只有一个核心世界设定，其他（地区、国家、文化、角色、情节）都还没想好的创作者。
>
> **你不需要：** 会编程、懂命令行、会用 Git。
>
> **你只需要：** 安装了 Claude Code，愿意一步步跟着走。

---

## 📌 写在前面：一句话理解 Claude Code

Claude Code 是一个**运行在终端里的 AI 助手**。它和网页版 Claude 聊天框最大的区别是：

| 网页版 Claude | Claude Code |
|:--|:--|
| 像临时聊天 | 像工作台 |
| 一次只能说一件事 | 能读文件、改文件、维护目录 |
| 对话一长就忘 | 通过文件系统永远不忘设定 |
| 适合聊灵感 | 适合做长线项目 |

**核心理念：不要把它当「写作机器人」，要把它当成「小说项目工程师」。**

长篇小说的真正难点不是写出第一章，而是写到第 80 章、第 200 章之后，依然：
- 角色动机不漂移
- 战力、时间线、世界规则不自相矛盾
- 伏笔有登记、有推进、有回收
- 爽点和节奏不疲劳

Claude Code 正是靠「文件系统 + 自动化流程」来解决这些问题。

## 🔧 阶段一：环境搭建（今天就可以做完）

### 1.1 确认 Claude Code 已安装

打开终端（Windows 上是 `cmd` 或 `PowerShell`），输入：

```bash
claude
```

如果能进入 Claude Code 的交互界面，说明已安装。如果不能，先去 [Claude Code 官网](https://claude.ai/claude-code) 按指引安装。

### 1.2 （可选但强烈推荐）安装网文写作专用工具包

目前社区有两套非常成熟的工具，你可以二选一，也可以都装：

#### 方案 A：oh-story-claudecode（⭐ 3161 stars）

**特点：** 覆盖扫榜→拆文→写作→去AI味→封面全流程，skill 包形式，轻量易上手。适配 Claude Code、OpenCode、Codex CLI 等多种 CLI。

安装方法——在 Claude Code 里直接说：

```
安装这个 skill https://github.com/worldwonderer/oh-story-claudecode
```

或者命令行：

```bash
npx skills add worldwonderer/oh-story-claudecode -y -g
```

安装后在 Claude Code 里输入 `/story-setup` 部署写作环境。之后你可以用这些命令：

| 命令 | 功能 |
|:--|:--|
| `/story-long-scan` | 扫榜分析市场趋势（起点/番茄/晋江） |
| `/story-long-analyze` | 拆解对标小说（黄金三章、爽点设计、节奏分析） |
| `/story-long-write` | 长篇写作（大纲搭建、人物设定、正文输出） |
| `/story-review` | 多视角审稿（4 Agent 多视角 + 评分标准） |
| `/story-deslop` | 去 AI 味（检测并清除 AI 写作痕迹） |
| `/story-import` | 导入已有小说（逆向解析为标准项目结构） |
| `/story-cover` | 封面生成（书名分析 + AI 出图） |

#### 方案 B：webnovel-writer（⭐ 5301 stars）

**特点：** 真正的「工程级」方案，有 RAG 语义检索、Story System 事实管理、可视化 Dashboard、Python 脚本驱动的投影系统，支持 200 万字级连载。解决 AI 写作中的「遗忘」和「幻觉」问题。

安装方法：

```bash
claude plugin marketplace add lingfengQAQ/webnovel-writer --scope user
claude plugin install webnovel-writer@webnovel-writer-marketplace --scope user
```

还需要安装 Python 依赖：

```bash
python -m pip install -r https://raw.githubusercontent.com/lingfengQAQ/webnovel-writer/HEAD/requirements.txt
```

然后在 Claude Code 里输入 `/webnovel-init` 初始化你的书。

核心命令：

| 命令 | 功能 |
|:--|:--|
| `/webnovel-init` | 深度初始化：搭骨架、设定集、总纲、初始状态 |
| `/webnovel-plan` | 卷纲规划：拆卷、拆章、补时间线 |
| `/webnovel-write` | 一章完整流水线：备上下文→起草→审查→润色→记录事实→备份 |
| `/webnovel-review` | 质量审查：爽点、一致性、节奏、OOC、连贯性、追读力 |
| `/webnovel-query` | 状态查询：角色、伏笔、节奏、实体关系 |
| `/webnovel-dashboard` | 只读可视化面板：实体图谱、章节内容、追读力数据 |
| `/webnovel-doctor` | 项目体检：目录、文件、数据库、RAG、依赖诊断 |

**两套怎么选？**
- 新手、想快速上手、喜欢轻量 → **方案 A**
- 要写 50 万字以上、追求最专业的项目管理 → **方案 B**
- 两个都装也可以，不冲突。很多作者先 A 后 B

### 1.3 建立你的小说项目目录（手动版）

如果你不想装工具包，也可以手动建立项目结构。推荐结构如下：

```

│   │   ├── 核心设定.md      # 你的核心世界观（已经有了）
│   │   ├── 契约系统.md      # 契约之力的详细规则和等级
│   │   ├── 地理.md          # 世界地图、大陆、国家、地区
│   │   ├── 种族.md          # 人类、吸血鬼、虫族、其他种族
│   │   ├── 历史.md          # 世界大事年表
│   │   └── 神树.md          # 神树的详细设定、能力和秘密
│   ├── 角色/                # 每个重要角色一个独立文件
│   │   ├── 主角.md
│   │   ├── 血色蔷薇.md
│   │   ├── 配角群.md
│   │   └── 反派.md
│   ├── 势力/                # 组织、国家、阵营
│   │   ├── 桃源村.md
│   │   ├── 吸血鬼势力.md
│   │   └── 外界势力.md
│   ├── 关系.md              # 角色关系映射图
│   └── 题材定位.md          # 核心梗概、对标分析、目标读者
├── 大纲/
│   ├── 大纲.md              # 全书卷级结构
│   ├── 卷纲_第一卷.md        # 每卷：爽点节奏+情绪弧线+伏笔+反转
│   └── 细纲_第001章.md       # 每章：内容概括+多线情节+钩子
├── 正文/
│   ├── 第001章_章名.md
│   └── ...
├── 追踪/                    # 写连载时持续维护
│   ├── 上下文.md            # 写作上下文（上下文压缩后恢复用）
│   ├── 伏笔.md              # 伏笔埋设/回收状态表
│   ├── 时间线.md            # 故事内时间线
│   └── 角色状态.md          # 角色当前状态快照
├── 对标/                    # 对标小说分析（从拆文库同步）
└── 参考资料/                # 研究资料（story-researcher 输出）
```

**如果装了工具包**，`/story-setup` 或 `/webnovel-init` 会自动帮你创建这个结构。

## 🌍 阶段二：世界观扩充（你现在最需要做的事）

你已经有了一个很棒的核心设定：「契约之力」、「植物棋子」、「中世纪奇幻」、「神树结界」、「虫族」、「吸血鬼」。现在需要从「核心」向外扩展。

### 2.1 核心方法论：苏格拉底式对话

**这是整个指南中最重要的方法论。**

不要让 Claude Code 一次性给你所有答案。更好的方式是：让它不断**问你问题**，逼你自己思考。这样设计出来的世界才是你真正喜欢的，而不是 AI 的模板产物。

在 Claude Code 里这样开始对话：

> 我现在有一个核心世界观：「神树之约」——中世纪奇幻世界，有契约之力、植物棋子、神树结界、虫族、吸血鬼。我想扩展这个世界观。
>
> 请先读取我的设定文件（世界观和剧情设定.md），然后不要给我结论，而是用苏格拉底式对话，一个问题一个问题地问我。每次我回答后，帮我把新设定记录到对应的设定文件中，然后继续下一个问题。
>
> 我们先从「地理与地区」开始。

### 2.2 世界观扩展的七大维度清单

拿着这个清单，在 Claude Code 里逐一攻克：

#### 🗺️ 维度一：地理与地区

核心问题——**桃源村的外面是什么？**

- [ ] 这个世界有几个大陆？面积多大？
- [ ] 桃源村在世界地图的哪个位置？（让 Claude Code 画 ASCII 地图）
- [ ] 外界有多少个国家/城邦/自由城？
- [ ] 有没有特殊地形？（上古战场、禁地、秘境、天险）
- [ ] 不同地区的气候、地貌、特产
- [ ] 交通方式？（传送阵？飞艇？魔兽坐骑？）
- [ ] 神树结界消失后，桃源村如何与外界连通？

#### 🏛️ 维度二：国家与势力

- [ ] 外界有哪些人类王国？之间的关系（同盟？世仇？）
- [ ] 政治体制（君主制？议会制？神权统治？魔法贵族？）
- [ ] 有没有跨国组织（教会、魔法学院、冒险者公会、商会）？
- [ ] 吸血鬼势力的内部结构——他们有自己的国家还是潜伏在人类社会中？
- [ ] 第三方势力：有没有中立商业城邦？秘密结社？
- [ ] 各大势力和「契约之力」的关系（崇拜？禁止？利用？恐惧？）
- [ ] 虫族是自然生物还是被人为制造/控制的？

#### 🎭 维度三：文化与习俗

- [ ] 不同地区对「契约」的信仰和态度（神圣？禁忌？日常工具？）
- [ ] 有没有契约相关的宗教/教派/神殿？
- [ ] 重要的节日、仪式、禁忌
- [ ] 契约者的社会地位（被崇拜？被恐惧？被当作武器利用？）
- [ ] 普通人对植物的态度（神树崇拜？万物有灵？）
- [ ] 吸血鬼的文化和人类有何不同？
- [ ] 教育体系：契约者如何训练？有没有学院？
- [ ] 艺术、建筑、服饰风格（不同地区的差异）

#### 📜 维度四：历史与时间线

- [ ] 「数百年前的大战」详细经过——参战方、关键战役、结局
- [ ] 「仙人」到底是什么存在？（人类？半神？穿越者？）
- [ ] 神树的真正来历——是仙人所种还是更古老的存在？
- [ ] 吸血鬼和仙人的恩怨根源
- [ ] 大战之后世界格局如何变化？
- [ ] 有没有被封印的上古力量或生物？
- [ ] 世界的重要历史节点（以百年为单位整理时间线）

#### ⚔️ 维度五：力量体系

- [ ] 契约之力分等级吗？（初级→中级→高级→血契？）
- [ ] 「阵图之仪」的具体过程和原理
- [ ] 六大器官在战斗中各有什么独特能力？
  - 根：吸收/控制地形/束缚
  - 茎：支撑/传导/连接
  - 叶：能量转化/伪装/范围攻击
  - 花：魅惑/治疗/爆发
  - 果：储存/强化/一次性爆发
  - 种：新生命/复活/扩散
- [ ] 除了植物，能否与其他生物/元素契约？
- [ ] 「血契」的代价和深层限制
- [ ] 是否有禁忌契约？（与死者契约？强迫契约？）
- [ ] 吸血鬼的特殊能力体系
- [ ] 世界上还有没有其他力量体系？（魔法？斗气？）
- [ ] 力量的来源是什么？（神树？世界本身？某种能量？）

#### 🧬 维度六：种族设定

- [ ] 人类：不同地区人类的差异（文化差异不是人种差异）
- [ ] 吸血鬼：生理特性（怕阳光？永生？吸血需求？）、社会结构、繁殖方式
- [ ] 有没有矮人、精灵、兽人、龙族等经典种族？
- [ ] 虫族：有没有更高阶的形态？虫巢意识？进化能力？
- [ ] 植物：除了蔷薇，还有多少种植物可以觉醒灵智？觉醒条件是什么？
- [ ] 有没有半契约者（失败实验的产物）？

#### 🔮 维度七：神树之谜（核心悬念）

- [ ] 神树有意识吗？会思考和交流吗？
- [ ] 神树的真正本质——是「树」还是某种更古老的意志？
- [ ] 结界衰败的真正原因
- [ ] 神树和「仙人」的真实关系
- [ ] 有没有其他神树存在？
- [ ] 如果神树死亡，世界会发生什么？
- [ ] 主角的特殊天赋和神树/仙人的关系

### 2.3 实操演示：你可以在 Claude Code 里直接这样对话

```
请读取我的「世界观和剧情设定.md」。

现在帮我扩展世界观。先用苏格拉底式对话，一次一个问题。
每次我回答后，立即把新设定写入对应的文件。

第一个问题：
桃源村之外，是一个怎样的世界？先给我一个宏观的框架——
这个世界有几个大陆？整体面积大概多大？人类文明主要分布在什么区域？
```

你会发现通过这样对话，原本模糊的「大世界」会逐渐被地形、国家、历史填充起来。

## 📖 阶段三：剧情与大纲深化

### 3.1 你的已有大纲是优质蓝本

你已经有了第一部的完整剧情框架：
- 序章：契约蔷薇
- 第一幕：虫灾爆发
- 第二幕：黑手现身
- 第三幕：三方大混战
- 尾声：走向大世界

这已经是一个非常好的三幕结构。Claude Code 可以帮你把它深化成可执行的章节计划。

### 3.2 让 Claude Code 帮你拆解大纲

```
请读取我的剧情大纲。现在帮我把它拆解为可写作的章节计划。

先分析：
1. 每一幕应该有多少章？（控制在 8-15 章/幕）
2. 每幕的情绪曲线应该怎样？（起→承→转→合→高潮）
3. 主角每幕结束时获得了什么新能力或新认知？
4. 每幕的高潮是什么？高潮之后如何过渡到下一幕？

不要一次给完，我们先从序章开始详细拆。
```

### 3.3 学习经典叙事套路（可选但强大）

在 Claude Code 里说：

```
请你去了解一下 TV Tropes（tvtropes.org）上以下叙事概念，
然后用我的「神树之约」设定来解释它们可以怎样应用：

1. Chekhov's Gun（契诃夫之枪）：第一幕出现的东西后面必须用上。
   在我的设定里，哪些元素可以成为「枪」？

2. Cliffhanger（章末悬念）：每章结尾怎么留钩子？
   给我的前 5 章各设计一个章末钩子。

3. Wham Episode（重击章节）：关键反转章节。
   我的故事里哪些节点可以做成 Wham Episode？

4. Death Is Cheap（死亡廉价化）：因为血契有生命共享，
   怎么避免死亡失去重量？

5. Body Horror（身体恐怖）：植物契约带来的身体变化。
   当主角获得蔷薇特征时，怎样描写才有视觉冲击力？
```

### 3.4 伏笔管理系统

长篇最重要的就是伏笔管理。在 Claude Code 里：

```
请帮我为「神树之约」第一部设计一个伏笔方案：

1. 跨卷伏笔（第一部埋，后面几部才回收的）：
   - 仙人的真实身份
   - 神树的秘密
   - 主角天赋的真正来源

2. 卷内伏笔（本卷内回收的）：
   - 虫灾的真正操控者
   - 吸血鬼宿敌的具体身份

3. 章节级伏笔（几章内回收的）：
   - 每个新植物的线索
   - 每次血契的代价

把这些记录到「追踪/伏笔.md」中，每条伏笔标记状态：
🌱 已埋 / 🌿 推进中 / 🌳 部分回收 / ✅ 已回收
```

## 👤 阶段四：角色塑造

### 4.1 角色文件模板

一个好角色不是「强大」或「善良」就够了，而是要有内心的矛盾：

```markdown
# 角色：[名字]

## 基础信息
- 年龄：
- 外貌特征：
- 出身和家庭背景：

## 性格的内核矛盾
- 表面上 ta 是……（别人眼中的 ta）
- 实际上 ta 是……（真实的 ta）
- ta 最不想让人知道的是……

## 动机系统
- 外在目标（ta 嘴上说想要什么）：
- 内在需求（ta 真正需要什么）：
- 这两者之间的矛盾是什么？

## 恐惧与创伤
- ta 最怕什么？
- 这种恐惧的根源是什么？
- ta 如何逃避这种恐惧？（ta 的防御机制）

## 能力与成长线
- 起点能力：
- 每卷获得什么：
- 成长的代价是什么：
- 最终形态：

## 语言风格
- 说话特点（句式长短、口头禅、用词习惯）：
- 在不同情绪下怎么变化：
- 有什么话 ta 永远不会说：

## 关键关系
- 与主角的关系本质和变化弧：
- 与其他重要角色的关系：
```

### 4.2 逐个塑造（苏格拉底式）

在 Claude Code 里，逐个角色来：

```
请帮我塑造「神树之约」的主角。
不要一次性写好全部，用苏格拉底式对话，一个问题一个问题问我。
每次我回答后，记录到「设定/角色/主角.md」中。

先问第一个问题：主角的年龄？在桃源村的身份和日常生活是怎样的？
```

你的角色清单（建议塑造顺序）：

1. **主角**（无名→需要你先给 ta 名字！）
2. **血色蔷薇**（它觉醒灵智了吗？能说话吗？什么性格？它愿意和主角契约吗？）
3. **仙人**（他/她是什么人？为什么隐退？在主角的故事里扮演什么角色？）
4. **吸血鬼宿敌**（不能是纯恶人——ta 的动机是什么？ta 恨仙人的理由站得住脚吗？）
5. **植物伙伴们**：向日葵（乐观阳光？）、卷心菜（沉稳厚重？）等——每株植物要有独特的性格和战斗风格
6. **村民角色**：村长/长老、主角的家人或朋友、对手/不服主角的同龄人
7. **未来的旅伴**：第二部主角走出村子后会遇到谁？

## ✍️ 阶段五：正式写作

### 5.1 黄金六步单章生产流程

这是博客作者写 70 万字的核心流程。**不要跳过任何一步。**

```
步骤 1：章节计划
   「请为第 1 章做章节计划，先不写正文。
    输出：本章目标、开头钩子、主要冲突、新信息、伏笔、
    反转、章末悬念、预估字数。」

步骤 2：检查计划
   「检查这个章节计划：
    - 有没有水字数？
    - 信息增量够不够？（这章结束后读者知道了什么上一章不知道的？）
    - 章末钩子够不够吸引人？
    - 主角有没有主动行动？（主角不能被动等待事件发生）
    - 和上一章有没有重复？」

步骤 3：写正文初稿
   「根据通过的计划写正文。2500-3500 字。
    要求：
    - 短句为主，每段不超过 3 行
    - 用具体场景和动作推进，不要大段解说
    - 每 800 字至少一次冲突或转折
    - 对话简短，像人说话不像念稿
    - 用五感描写（看、听、闻、触、味）
    - 章末必须有追读钩子」

步骤 4：编辑审稿
   「作为网文编辑审查本章：
    - 哪三段最水？（具体指出）
    - 哪个冲突不够强？
    - 有没有人物说话不像真人？
    - 哪些地方像 AI 写的？（解释腔、总结腔、每段收太圆）
    - 读者最可能在哪里弃读？
    - 章末钩子够不够？」

步骤 5：定点重写
   「只重写第 X、Y 段。
    - 加强怪物/战斗的压迫感
    - 删除解释性总结，用动作替代
    - 对话缩到最短
    - 结尾钩子更狠一点」

步骤 6：更新设定库
   「根据本章新内容，更新以下文件：
    - 追踪/伏笔.md（新增或推进的伏笔）
    - 追踪/角色状态.md（角色位置、心理状态、新能力）
    - 追踪/时间线.md（本章发生的时间点）
    - 如有新设定，更新对应设定文件」
```

### 5.2 写作提示词模板

#### 日常正文写作

```
你是一位熟悉番茄/起点风格的中国网文作者。

即将写作「神树之约」第 N 章。

【本章上下文】（从追踪文件读取）
- 上一章结尾：……
- 当前角色状态：……
- 待回收的伏笔：……

【本章目标】
……

【风格要求】
- 短句，每段不超过 3 行
- 动作推进，少解释
- 对话简短，像真人说话
- 不用「他意识到」「他终于明白」「他心中涌起」等总结腔
- 用具体身体细节替代心理描写
- 留一点口语的不完整感，不要每段都收得太圆
- 每 800 字至少一次冲突升级

【字数】2500-3500 字
```

#### 战斗场景专用提示词

```
写棋盘上植物 vs 虫族的战斗。
【要求】
- 短句 + 快速动作，节奏要紧凑
- 明确写出每种植物器官棋子（根茎叶花果种）的独特作用和配合
- 虫群的视觉冲击：数量、形态变化、声音、气味
- 主角的战术决策要有逻辑，不是无脑指挥
- 战斗要有三到四个起伏，不能平推
- 每次局势转折要有原因（新虫子出现、器官被破坏、新战术）
- 结尾留悬念——这一波打完了，但更危险的还在后面
- 把植物器官的伤亡写成真实的损失感
```

### 5.3 去 AI 味——单独跑一轮

AI 初稿最容易出现这些问题：

| AI 味症状 | 具体表现 | 怎么改 |
|:--|:--|:--|
| 总结腔 | 「他意识到……」「他终于明白……」 | 删掉，让读者自己感受 |
| 解释腔 | 把角色的每个情绪都解释一遍 | 用表情、动作、对话暗示 |
| 收尾太圆 | 每段都像一个小结论 | 段落留一点开放感 |
| 对话像演讲 | 角色说话像在做报告 | 缩到 10 字以内，加语气词 |
| 排比过度 | 「有的……有的……还有的……」 | 只保留最具冲击力的一个 |
| 形容词堆砌 | 「巨大的、恐怖的、令人窒息的」 | 选一个最准确的，用具体细节替代 |
| 视角跳跃 | 一会儿写主角心理，一会儿写反派心理 | 固定视角，一场景一视角 |

**去 AI 味提示词：**

```
请审查本章的 AI 味，逐句修改：

1. 删除所有「他意识到」「他终于明白」「他心中涌起」「他感到一阵」开头的句子，
   用具体动作或对话替代。

2. 所有超过 20 字的对白缩到 15 字以内。

3. 删除段末的总结性句子。

4. 心理活动不超过全文的 10%，且必须用「具体想法」而非「情绪概括」来表达。

5. 检查有没有连续三段以相同句式开头。

6. 不要把所有情绪都解释清楚。留白也是一种写法。

7. 如果一段话读起来像「教科书式的好文笔」，那就要重写。
```

如果用 oh-story-claudecode，直接 `/story-deslop` 即可自动化这个过程。

## 🧰 进阶技巧

### 技巧一：多 Agent 协作审稿

Claude Code 支持多个子 Agent 同时工作。oh-story-claudecode 内置了 7 个专业 Agent：

| Agent | 模型 | 职责 |
|:--|:--|:--|
| story-architect | Opus | 故事架构、题材定位、大纲结构、钩子/反转设计 |
| character-designer | Sonnet | 角色设计、语言风格、动机链、对话创作 |
| narrative-writer | Sonnet | 正文写作、去 AI 味、格式合规 |
| consistency-checker | Haiku | 一致性检查、事实冲突扫描、伏笔追踪、分级报告 |
| story-researcher | Sonnet | 资料研究、CDP 搜索+正文提取、多源交叉验证 |
| story-explorer | Haiku | 角色/伏笔/设定/进度只读查询，日更上下文快速加载 |
| chapter-extractor | Haiku | 章节提取、摘要+情节点+角色提及、并行拆文 |

用法：直接在对话中调用，例如：

```
让 consistency-checker agent 检查我最近 10 章的设定一致性。
让 story-architect agent 看一下后续 10 章的大纲是否有结构问题。
```

webnovel-writer 也有类似的 context-agent、reviewer、data-agent 体系。

- 血契 = 生命共享，一方死则双方亡

- 对话不超过 3 句连续
- 禁止 AI 总结腔

## 角色速查
- 主角：[名字] - 当前状态：……
- 蔷薇：已缔结血契 - 当前状态：……

### 技巧三：角色对话声线管理

让你的每个角色「听起来不一样」：

```
分析我现有角色的对话风格，帮我为每个角色建立「声线档案」：
- 每个人有不同的口头禅
- 不同句长偏好（有人爱说短句，有人爱绕弯子）
- 不同用词范围（有人文绉绉，有人粗俗）
- 在不同情绪下的变化

然后检查我最近 5 章的对话，有没有角色串味？
```

### 技巧四：对标分析

如果你有喜欢的同类型小说：

```
请分析《XXX》（或你喜欢的同类型作品）的前 10 章：
1. 每章的章节结构和节奏
2. 爽点的类型和分布
3. 对话占比 vs 描写占比
4. 章末钩子的类型
5. 读者评论的高频关键词
6. 开头三章的黄金公式

然后对比我的小说，给出差异分析和改进建议。
```

### 技巧五：读者模拟

```
请模拟三种类型的读者，分别阅读我最近写的章节并给出反馈：

1. 追读型读者：每天追更，最关心「下一章发生什么」
   - 追读动力在哪里减弱？
   
2. 爽文型读者：只要爽点，不想动脑
   - 爽点密度够不够？有没有连续 3 章不升级/不打/不反转？
   
3. 考据型读者：在意设定严谨性
   - 有没有逻辑漏洞？设定自相矛盾？
```

## ⚠️ 新手常见陷阱 & 解决方案

| 坑 | 为什么危险 | 怎么避免 |
|:--|:--|:--|
| 让 AI 自由发挥 | AI 默认走最套路路线，角色扁平、节奏机械 | 每章必须给：本章目标 + 风格要求 + 禁止事项 |
| 「写得精彩一点」 | 太模糊，AI 不知道具体改什么 | 说具体：「对话缩到 10 字」「用动作替代心理」「增加身体恐怖细节」 |
| 不维护追踪文件 | 写到 30 章后忘记前面的伏笔和设定 | 每章写完立即更新追踪文件，形成肌肉记忆 |
| 设定只在脑子里 | 写着写着前后矛盾，读者发现漏洞 | 一切设定落地成文件。写新章前先 grep 相关设定 |
| 不单独审稿 | 初稿 AI 味重，读者一眼出戏 | 必须单独跑审稿 + 去 AI 味，不要指望初稿直接能用 |
| 大纲太死 | 写着发现更精彩的方向但不敢改 | 大纲是地图不是铁轨。每 10 章回顾，该改就改 |
| 一次写太多 | 质量下降 + 忘了设定 → 崩盘 | 一天最多 1-2 章，写完必须审稿 |
| 忽略了「信息增量」 | 连续几章主线没有推进 → 读者弃读 | 每章必须新增至少一件：新怪物/新规则/新信息/新关系/新代价 |
| 场景描写过多 | 读者跳过大段环境描写，只找对话 | 场景描写控制在 3 行以内，融入动作中，不要单独一大段 |
| 心理活动泛滥 | 读者不在意思考过程，只看行动和结果 | 心理活动不超过全文 10%，用行为暗示内心 |

> **最后的话：**
>
> 你不需要一次性把所有东西都想好。写作是一个迭代的过程。
>
> 第一遍，你只需要一个「足够好」的世界观。
> 第二遍，在写的过程中会发现更多细节。
> 写到第十遍，你的世界会比你最初想象的丰富一百倍。
>
> Claude Code 不是替你「想」，而是帮你「记住」和「提醒」。
> 真正让世界活起来的，还是你的想象力。
>
> 你的「神树之约」已经有了非常好的种子：
> - **契约之力**——一个可以生出无数故事的核心机制
> - **植物棋子**——非常独特、有视觉辨识度的战斗系统
> - **神树结界**——天然的故事引擎（结界衰败=倒计时）
> - **虫族+吸血鬼**——有层次的反派组合（无脑+有智）
> - **死亡回档式血契**——主角的每一步胜利都有真实代价
>
> 接下来要做的，就是让这颗种子生根、发芽、开出属于你的故事之花。
>
> 现在，打开终端，开始吧。🚀
