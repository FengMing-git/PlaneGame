## 二、模块职责与边界

### 架构层级

```
                        ┌─────────────┐
                        │  core/      │  纯函数 + 数据容器
                        │  游戏逻辑   │  不知道上层是谁
                        └──────┬──────┘
                               │
               ┌───────────────┼───────────────┐
               │                               │
      ┌────────▼────────┐            ┌─────────▼─────────┐
      │  simulator/     │            │  proto/           │
      │  AI 决策 + 统计 │            │  Canvas 渲染+输入 │
      │  CLI 入口       │            │  HTML 页面        │
      └─────────────────┘            └───────────────────┘
```

### core 对外暴露的最小接口

```typescript
// 创建
createGameState(config: GameConfig): GameState

// 推进回合
executePhase(state: GameState, phase: TurnPhase): GameEvent[]
executeFullTurn(state: GameState): { state: GameState; events: GameEvent[] }

// 行动系统（回合进行时）
getLegalActions(state: GameState): Action[]
executeAction(state: GameState, action: Action): { state: GameState; events: GameEvent[] }

// 查询
checkWinCondition(state: GameState): GameResult | null
canAffordUpgrade(state: GameState, type: UpgradeType): boolean
```

### AI 与 core 的边界

```
┌─── AI 的职责 ──────────────────┐   ┌─── core 的职责 ───────────────┐
│                                │   │                              │
│  1. 调用 getLegalActions()     │   │  1. 根据当前状态生成所有合法   │
│     拿到候选列表                │   │     行动（移动/攻击/播种/升级） │
│                                │   │                              │
│  2. 对每个候选行动评分          │   │  2. 执行 AI 选定的行动         │
│                                │   │     executeAction(state, act)  │
│  3. 选最高分行动               │   │                              │
│     act = pickBest(candidates) │   │  3. 返回新状态 + 事件列表      │
│                                │   │                              │
│  4. 把行动交给 core 执行       │   │  4. 验证行动合法性（防作弊）    │
│                                │   │                              │
└────────────────────────────────┘   └──────────────────────────────┘

AI 永远不直接修改 GameState。
AI 只知道行动列表和评分，不知道棋盘内部实现。
```

### Action 类型定义

```typescript
type Action =
  | { type: 'MOVE';     to: Pos }
  | { type: 'ATTACK';   targetId: number }
  | { type: 'SOW';      at: Pos }
  | { type: 'UPGRADE';  upgrade: 'atk' | 'def' | 'hp' | 'ap' }
  | { type: 'END_TURN' }
```

AI 拿着这个列表，评分、挑一个、还给 core。就这么简单。

## 四、Simulation 生命周期

### 单次模拟

```
SimulationRunner.run(config, map)
  │
  ├─ 1. GameState.init(config, map)
  ├─ 2. StatCollector.init()
  ├─ 3. AIController.init()
  │
  ├─ 4. LOOP:
  │   │
  │   ├── TurnEngine.executeTurnStart(state)
  │   ├── TurnEngine.executeTurnPrep(state)
  │   │
  │   ├── // 回合进行时：AI 决策循环
  │   ├── actions = getLegalActions(state)
  │   ├── WHILE (actions.length > 0):
  │   │   ├── action = AIController.pick(actions)
  │   │   ├── { state, events } = executeAction(state, action)
  │   │   ├── StatCollector.onEvents(events)
  │   │   └── actions = getLegalActions(state)
  │   │
  │   ├── TurnEngine.executeTurnEnd(state)
  │   ├── TurnEngine.executeTurnTermination(state)
  │   │
  │   ├── StatCollector.recordTurn(turn, state)
  │   │
  │   ├── result = checkWinCondition(state)
  │   └── IF result THEN BREAK
  │
  ├─ 5. StatCollector.finalize(result)
  └─ 6. return SimulationReport
```

### 批量运行

```
BatchRunner.run(100, config)
  │
  ├── FOR i = 0 TO 100:
  │   ├── seed = config.seed ?? random()
  │   └── reports[i] = SimulationRunner.run(config, map, seed)
  │
  ├── batch = aggregate(reports)
  └── CSVExporter.write(batch, "./output/batch.csv")
```

### 终局事件

| 事件 | 触发条件 |
|------|---------|
| WIN_ALL_CLEAR | 所有敌人被消灭 |
| WIN_CAPTURE | 指定地块被占领 |
| WIN_SURVIVE | 存活到指定回合 |
| LOSE_PLAYER_DEAD | 玩家 HP <= 0 |
| LOSE_DEADLOCK | 无种子、无果、资源不足以转化 |
| DRAW_TIMEOUT | 超过 maxTurns |

## 五、核心数据结构

所有类型定义在 `core/src/types.ts`，这是 core 和 simulator 共享的唯一类型文件。

```typescript
// === 基础 ===
type Pos = { x: number; y: number; };
type ResourceTriple = { water: number; light: number; earth: number; };
type PieceType = 'seed' | 'root' | 'stem' | 'leaf' | 'flower' | 'fruit';
type EnemyAI = 'aggressive' | 'calm' | 'passive';
type TurnPhase = 'start' | 'prep' | 'action' | 'end' | 'termination';

// === 棋子 ===
interface Piece {
  id: number; type: PieceType; owner: 'player' | 'enemy';
  hp: number; maxHp: number; active: boolean;
}

// === 地块 ===
interface Tile {
  pos: Pos; type: string;
  output: ResourceTriple;    // 每回合产出
  stock: ResourceTriple;     // 当前积存
}

// === 玩家 ===
interface PlayerState {
  pos: Pos;
  hp: number; maxHp: number; atk: number; def: number;
  ap: number; maxAp: number;
  handFruit: number;
  upgrades: { atk: number; def: number; hp: number; ap: number; };
}

// === 资源池 ===
interface ResourcePool {
  water: number; light: number; earth: number; nutrient: number;
}

// === 敌人 ===
interface Enemy {
  id: number; templateId: string; pos: Pos;
  hp: number; maxHp: number; atk: number; def: number;
  moveRange: number; attackRange: number; ai: EnemyAI;
}

// === 游戏状态 ===
interface GameState {
  board: { width: number; height: number; tiles: Tile[][]; pieces: Piece[][]; };
  player: PlayerState;
  resources: ResourcePool;
  enemies: Enemy[];
  turn: number;
  phase: TurnPhase;
  result: GameResult | null;
}

// === 行动 ===
type Action =
  | { type: 'MOVE';     to: Pos }
  | { type: 'ATTACK';   targetId: number }
  | { type: 'SOW';      at: Pos }
  | { type: 'UPGRADE';  upgrade: 'atk' | 'def' | 'hp' | 'ap' }
  | { type: 'END_TURN' };

// === 事件（StatCollector 订阅） ===
type GameEvent =
  | { type: 'PIECE_CREATED';     turn: number; pieceId: number; pieceType: PieceType; pos: Pos }
  | { type: 'PIECE_DESTROYED';   turn: number; pieceId: number; cause: string }
  | { type: 'PIECE_ACTIVATED';   turn: number; pieceId: number }
  | { type: 'COMBAT';            turn: number; attacker: string; defender: string; damage: number }
  | { type: 'RESOURCE_PRODUCED'; turn: number; pos: Pos; water: number; light: number; earth: number }
  | { type: 'RESOURCE_COLLECTED';turn: number; water: number; light: number; earth: number }
  | { type: 'RESOURCE_CONSUMED'; turn: number; pieceId: number; water: number; light: number; earth: number }
  | { type: 'RESOURCE_WASTED';   turn: number; pos: Pos; water: number; light: number; earth: number }
  | { type: 'UPGRADE';           turn: number; upgradeType: string; level: number }
  | { type: 'ENEMY_MOVED';       turn: number; enemyId: number; from: Pos; to: Pos }
  | { type: 'ENEMY_ATTACKED';    turn: number; enemyId: number; target: string; damage: number }
  | { type: 'FRUIT_HARVESTED';   turn: number; count: number }
  | { type: 'GAME_END';          turn: number; result: GameResult };

// === 胜负 ===
type GameResult =
  | { type: 'win';  condition: string }
  | { type: 'lose'; condition: string }
  | { type: 'draw'; reason: string };
```

### 6.3 经济指标（新增重点）

```typescript
interface EconomyMetrics {
  // === 资源浪费率 ===
  // 每回合浪费的资源 / 总产出
  perTurnWasteRate: number[];
  overallWasteRate: number;       // 累计浪费/累计产出

  // === 植物 ROI（投入产出比） ===
  plantROI: {
    // 每株植物：生命周期总产出资源 / 总消耗资源
    byPlant: {
      average: number;            // 所有植物平均 ROI
      median: number;
      distribution: number[];     // 每株植物的 ROI 列表
    };
    // 按创建时期分组
    byAge: {
      earlyROI: number;           // 前 5 回合创建的植物
      midROI: number;             // 6-15 回合创建的植物
      lateROI: number;            // 16+ 回合创建的植物
    };
    // 亏损植株
    unprofitableCount: number;    // ROI < 1 的植物数
    unprofitableRate: number;
  };

  // === 资源时间曲线（全量时序） ===
  resourceTimeCurve: Array<{
    turn: number;
    water: number;               // 存量
    light: number;
    earth: number;
    nutrient: number;
    fruit: number;
    waterProduced: number;       // 本回合产出
    waterConsumed: number;       // 本回合消耗
    waterWasted: number;         // 本回合浪费
  }>;

  // === 盈亏平衡 ===
  breakEvenTurn: number | null;  // 首次累计收集 > 累计消耗
  breakEvenByResource: {
    water: number | null;
    light: number | null;
    earth: number | null;
  };

  // === 果经济 ===
  fruitEconomy: {
    totalSown: number;           // 总播种次数
    totalHarvested: number;      // 总收获果数
    conversionRate: number;      // 利用率 = sown/harvested
    avgFruitPerTurn: number;     // 每回合平均果收入
    fruitPerPlant: number;       // 每株植物生命周期产果数
  };
}
```

## 九、AI 单策略设计（Phase 1 唯一 AI）

```typescript
function greedyEvaluate(state: GameState, action: Action): number {
  switch (action.type) {
    case 'ATTACK':
      // 优先消灭残血敌人
      const enemy = state.enemies.find(e => e.id === action.targetId)!;
      return 100 + (1 - enemy.hp / enemy.maxHp) * 50;

    case 'SOW':
      // 果多时倾向播种，地块产出越高分越高
      const tile = state.board.tiles[action.at.y][action.at.x];
      const fruitBonus = state.player.handFruit >= 3 ? 30 : 0;
      return 20 + (tile.output.water + tile.output.light + tile.output.earth) + fruitBonus;

    case 'UPGRADE':
      // 优先级: AP > ATK > DEF > HP
      const priority: Record<string, number> = { ap: 40, atk: 30, def: 20, hp: 10 };
      return priority[action.upgrade];

    case 'MOVE':
      // 向最近敌人靠近
      const nearest = findNearestEnemy(state);
      return 15 - manhattanDist(action.to, nearest.pos);

    case 'END_TURN':
      return -100;  // 没 AP 或没更好行动时才结束

    default:
      return 0;
  }
}
```

Phase 1 只此一种 AI。Phase 3 引入多策略对比。
