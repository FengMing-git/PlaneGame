# 植物棋类策略游戏 —— 规则文档

> **版本**: v0.4  
> **类型**: PvE 回合制策略  
> **主题**: 植物生存——植物之间的领地争夺、植物与昆虫的对抗

---

## 一、棋盘

- **形状**: 正方形方格网格
- **大小**: 不固定，每关不同（如 6×6、8×8、10×10）
- **地块**: 每个地块有固定的水/光/土资源产出量，不同类型产出不同

---

## 二、棋子（共 7 类）

### 2.1 棋子总览

| 棋子 | 阵营 | 能否移动 | HP | 核心功能 |
|------|------|---------|-----|---------|
| 玩家 | 己方 | ✅ | `HP_玩家` | 执行所有主动操作 |
| 种 | 己方 | ❌ | 1 | 播种后发芽，生成根+茎+叶 |
| 根 | 己方 | ❌ | 1 | 占领地块，生成茎 |
| 茎 | 己方 | ❌ | 1 | 生成花和叶；阻挡敌方 |
| 叶 | 己方 | ❌ | 1 | 每回合产出养分 |
| 花 | 己方 | ❌ | 1 | 消耗自身产出果 |
| 果 | 己方 | ❌ | 1 | 双重身份：棋子 & 强化攻击资源 |

### 2.2 各棋子详细行为

#### 玩家
- 属性：HP / ATK / DEF / AP（行动力）
- 在「回合进行时」消耗 AP 执行操作：

| 操作 | AP 消耗 | 说明 |
|------|---------|------|
| 移动 | `COST_移动` | 移动 1 格 |
| 普通攻击 | `COST_攻击` | 攻击相邻 4 格内目标 |
| 强化攻击 | `COST_攻击` + 1 果 | 直线无限射程 |
| 播种 | `COST_播种` | 将果转化为种，放置于当前格 |
| 资源转化 | `COST_转化` | 资源互换（规则待定） |
| 释放技能 | 待定 | 玩家特殊技能 |

- 可通过消耗资源永久提升属性（消耗比例待定）

#### 种（Seed）
- **回合开始时**: 「发芽」——移出自身，在**所在地块**生成 1 个 `根` + 1 个 `茎`，在**周围四格**中按 **上→右→下→左** 顺序选 1 个空地块生成 1 个 `叶`
- **回合终止时**: 消耗 `C_种_水`水 + `C_种_光`光 + `C_种_土`土
  - 资源不足 → **休眠**：不消耗资源，不发芽，停在此状态直到所在地块资源满足消耗需求，下回合恢复

#### 根（Root）
- **回合开始时**: 若所在地块没有 `茎`，则生成 1 个 `茎`
- **回合终止时**: 消耗 `C_根_水`水 + `C_根_光`光 + `C_根_土`土
  - 资源不足 → **枯萎**（移出棋盘）

#### 茎（Stem）
- **占用效果**:
  - 敌方移动到茎所在格时，AP 额外消耗 +1（多个茎叠加）
  - `果` 的强化攻击穿过茎时，伤害 × `M_茎_减伤系数`
- **回合开始时**（每回合限生成 1 个棋子，按优先级）:
  1. 若所在地块无 `花` → 生成 1 个 `花`（「开花」）
  2. 否则，若周围 4 格有地块无 `叶` → 按上→右→下→左顺序，在第一个无叶地块生成 1 个 `叶`
- **回合终止时**: 消耗 `C_茎_水`水 + `C_茎_光`光 + `C_茎_土`土
  - 资源不足 → **枯萎**

#### 叶（Leaf）
- **回合开始时**: 产出 `P_叶_养分产量` 养分
- **回合终止时**: 消耗 `C_叶_水`水 + `C_叶_光`光 + `C_叶_土`土
  - 水不足 → 枯萎
  - 光不足 → 下回合不产养分（但自身不枯萎）

#### 花（Flower）
- **回合开始时**: 「结果」——移出自身，在所在地块生成 1 个 `果`
- **回合终止时**: 消耗 `C_花_水`水 + `C_花_光`光 + `C_花_土`土
  - 资源不足 → **枯萎**

#### 果（Fruit）
- 双重身份：棋子 & 资源
- **回合预备时**: 棋盘上的果自动收入玩家手牌
- **作为棋子**: `K_果转种` 个果 → 转化为 1 个 `种`
- **作为资源**: 攻击时可消耗 1 个果发动「强化攻击」
- 果棋子不消耗地块资源

## 三、敌人系统

### 3.1 敌人类型
- **昆虫**: 主动入侵者，有 AI 行为模式
- **敌方植物**: 与玩家争夺地块资源，同样播种、生长、消耗资源

### 3.2 敌人 AI 行为模式（参考火焰纹章）

| 类型 | 行为 |
|------|------|
| **主动型** | 每回合向最近的玩家/己方棋子移动，进入攻击范围即攻击 |
| **冷静型** | 原地待机，玩家棋子进入攻击范围时才行动 |
| **不动型** | 不移动，被攻击时反击 |

### 3.3 敌人属性
- 每个敌人独立拥有：HP / ATK / DEF / 移动力 / 攻击范围
- 可攻击目标：玩家、己方棋子（根/茎/叶/花/种/果）
- 敌方植物遵循与己方相同的资源消耗规则

## 四、战斗系统

### 4.1 伤害公式

```
伤害 = max( 攻击方ATK − 防御方DEF , 1 )
```

### 4.2 攻击类型

| 攻击 | 范围 | 消耗 | 特殊 |
|------|------|------|------|
| 普通攻击 | 相邻 4 格 | `COST_攻击` AP | — |
| 强化攻击 | 直线无限（四方向选一） | `COST_攻击` AP + 1 果 | 穿过茎时伤害 × M_茎_减伤系数 |

### 4.3 棋子被攻击
- 己方棋子 HP = 1，受到 ≥1 伤害即被摧毁
- 敌方棋子 HP 由关卡配置决定

### 4.4 伤害计算流程
```
1. 取攻击方 ATK
2. 减去防御方 DEF
3. 若结果 < 1，取 1
4. 施加伤害
```

> 未来可扩展：防御前 ATK 增益、防御后伤害倍率、固定附伤

## 五、胜负条件

### 胜利条件（每关设定其一）

| 条件 | 说明 |
|------|------|
| **敌全灭** | 消灭地图上所有敌人（默认） |
| **占领地块** | 在指定地块上生成己方 `根` |
| **击败 Boss** | 消灭指定 Boss 单位 |
| **存活回合** | 存活 N 回合 |

### 失败条件（任一触发）
- 玩家 HP ≤ 0
- 不可逆死局：无种、无果、且资源不足以转化出种

## 六、资源系统

### 6.1 资源类型

| 资源 | 来源 | 用途 |
|------|------|------|
| 水 | 地块产出 | 棋子消耗 |
| 光 | 地块产出 | 棋子消耗 |
| 土 | 地块产出 | 棋子消耗 |
| 养分 | 叶产出 | 万用资源，可 1:1 替代水/光/土 |
| 果 | 花产出 | 强化攻击 / 播种 |

### 6.2 地块资源产出
- 每回合结束时，每个地块产出固定的水/光/土
- **衰减机制**：从第 `T_衰减开始` 回合起，每回合所有地块产出量 -`D_衰减量`，直至归零
- **后期伤害**：从第 `T_衰减开始` 回合起，每回合回合预备时玩家受到 `DOT_后期` × 玩家最大 HP 的无来源伤害

### 6.3 资源收集
- 回合预备时：玩家收集**所在地块** + **所有己方根所在地块**上的当期资源
- 未被收集的地块资源：消失

---

## 七、回合结构

```
回合开始时 → 回合预备时 → 回合进行时 → 回合结束时 → 回合终止时
```

| 阶段 | 事件 |
|------|------|
| **回合开始时** | ① 棋子自主行为（按结算顺序）② Buff/Debuff 结算 ③ 敌人 AI 决策 |
| **回合预备时** | ① 收集占领地块资源 ② 果自动收入玩家手牌 |
| **回合进行时** | 玩家操作（移动/攻击/播种/转化/技能） |
| **回合结束时** | 所有地块产出资源 |
| **回合终止时** | 所有棋子消耗资源；资源不足 → 枯萎/休眠 |

### 同一地块棋子结算顺序
```
根 → 叶 → 茎 → 花 → 果 → 种
```

## 九、完整游戏流程示例

> 假设：6×6 棋盘，玩家初始携带 3 个果，无敌人（纯运营演示）

### 整体节奏

| 阶段 | 回合 | 核心目标 |
|------|------|---------|
| **前期** | 1~5 | 播种 + 建立植株体系 |
| **中期** | 6~20 | 果量产，主动进攻/扩张 |
| **后期** | 21+ | 资源衰减 + 持续扣血，必须终结对局 |

### 逐回合推演

#### 第 1 回合 —— 首次播种
| 阶段 | 事件 |
|------|------|
| 回合开始 | 场上无棋子，无事发生 |
| 回合预备 | 收集玩家初始格资源 |
| 回合进行 | 玩家移动至目标格，消耗 1 果 → 播种（放置**种₁**） |
| 回合结束 | 各地块产出水/光/土 |
| 回合终止 | **种₁**消耗所在格资源 |

#### 第 2 回合 —— 第一株发芽
| 阶段 | 事件 |
|------|------|
| 回合开始 | **种₁发芽**：移除自身，所在格生成**根₁+茎₁**，相邻空地块生成**叶₁** |
| 回合预备 | 收集玩家所在格 + 根₁所在格的资源 |
| 回合进行 | 玩家移动，消耗果播种**种₂**（或暂留资源） |
| 回合结束 | 各地块产出资源 |
| 回合终止 | **种₂**、**根₁**、**茎₁**、**叶₁**消耗各自所在格资源 |

#### 第 3 回合 —— 茎开花
| 阶段 | 事件 |
|------|------|
| 回合开始 | **种₂发芽**（生成根₂+茎₂+叶₂）；**茎₁开花**（所在格生成**花₁**） |
| 回合预备 | 收集玩家所在格 + 根₁、根₂所在格的资源 |
| 回合进行 | 玩家操作（移动/播种种₃/攻击敌人/资源转化） |
| 回合结束 | 各地块产出 |
| 回合终止 | 所有棋子消耗资源 |

#### 第 4 回合 —— 叶产养分，花结果
| 阶段 | 事件 |
|------|------|
| 回合开始 | **叶₁、叶₂**产出养分；**花₁结果**（移除自身，生成**果₁**） |
| 回合预备 | 收集资源，**果₁**自动收入手牌 |
| 回合进行 | 手中有果，可选择用果强化攻击，或留到下次播种 |
| 回合结束 | 各地块产出 |
| 回合终止 | 所有棋子消耗资源 |

#### 第 5 回合 —— 植株体系成型
| 阶段 | 事件 |
|------|------|
| 回合开始 | **叶**继续产养分；**花₂**（若有）结果；**茎**继续扩叶 |
| 回合预备 | 手牌收入新果；收集占领格资源 |
| 回合进行 | 手中已有 ≥2 果，可选：① 强化攻击 ② 继续播种扩张 ③ 资源转化为 HP |
| 回合结束 | 产出 |
| 回合终止 | 消耗 |

#### 第 6~20 回合（中期）
- 植株体系持续运转：叶→养分，花→果，手牌果数量递增
- 每回合 1~2 个果入账，可稳定发动强化攻击
- 决策点：**速攻**（用果直接攻击敌人）vs **扩张**（果转种，扩大领地）
- 敌方植物也会生长，双方争夺地块和资源

#### 第 21 回合起（后期）
- 回合预备时：所有地块产出量 -1；玩家受到 10% 最大 HP 伤害
- 产出下降 → 棋子消耗跟不上 → 植株陆续枯萎
- 必须在此之前终结对局，否则被资源枯竭拖死

## 十、棋子系统状态转换图

```
果 ──(播种,消耗K个果)──→ 种
                           │
                     (回合开始:发芽)
                           ↓
                    根 + 茎 + 叶
                    │    │     │
                    │    │     └──(回合开始)→ 产养分
                    │    │
                    │    ├──(回合开始,无花)→ 花
                    │    │                      │
                    │    │                (回合开始:结果)
                    │    │                      ↓
                    │    │                     果 → 回玩家手牌
                    │    │
                    │    └──(回合开始,有花且周围缺叶)→ 叶
                    │
                    └──(回合开始,无茎)→ 茎

所有棋子(除果):
  回合终止时消耗资源
  ├── 够 → 存活
  └── 不够 → 枯萎(移出) 或 休眠(种专用)
```
