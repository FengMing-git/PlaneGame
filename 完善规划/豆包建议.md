# 植物对战棋：分步自主完善落地指南

前言：你现在已经完成了**核心概念层**（主题、棋子定位、资源体系、胜负条件、动态/静态棋子区分）。接下来不需要新增创意，只需要**补全规则、定义边界、建立制衡、打磨数值、验证可玩性**。所有步骤循序渐进，不可跳步。

## 阶段一：固化基础底层框架（第一步必做）

本阶段目标：彻底解决“概念模糊”，定下游戏所有**不变的底层规则**，后续所有设计全部基于这一层，不再改动。

你需要独立确定、记录以下5项内容：

1. **棋盘规则**：棋盘尺寸、格子类型、每个格子是否固定单一资源（光/土/水三选一）、是否存在空白无资源地块。
2. **对局基础数值**：玩家初始HP上限、对局最大回合数（防无限苟局）。
3. **回合固定流程**：严格规定每一回合的操作顺序（资源结算、移动、放置棋子、攻击、释放技能、回合收尾），必须线性固定，不能乱序。
4. **棋子通用规则**：静态棋子（根茎叶花果种）是否可被摧毁、是否可被覆盖、死亡后是否可再生；玩家本体棋子死亡规则。
5. **基础判定规则**：伤害结算优先级、buff/debuff覆盖规则、占地判定标准。

本阶段验收标准：任何一个新人看完规则，能完整走完一整局空对局，无任何规则疑问。

## 阶段二：细化资源系统（第二步）

资源是你游戏的核心滚雪球与制衡核心，目前最大问题：三种资源定位模糊。

你需要独立完成三点设计：

1. **资源专属功能拆分**：保证光、土、水**用途完全不重叠**。每种资源只能负责一类功能（例如：输出、生存、运营三权分立），杜绝三种资源作用同质化。
2. **资源获取规则**：占据地块如何产资源、单回合资源上限、劣势玩家是否有额外资源补偿（反滚雪球）。
3. **资源消耗场景全覆盖**：放置棋子、释放技能、触发天赋、回血、强化buff，分别消耗什么资源。

验收标准：玩家无法只用单一资源通关，必须搭配三种资源，策略才有取舍。

## 阶段三：完整定义7类棋子机制（第三步）

你目前只有棋子功能定位，没有可执行规则。按统一模板，逐个完善每一颗棋子。

每一个棋子（根、茎、叶、花、果、种、本体）统一补充5项参数：

1. 放置条件：需要消耗什么资源、是否占格子、能否叠加
2. 生效范围：自身、相邻一格、全屏、所属地块
3. 具体效果：数值化（伤害、移速、增益、占地效果）
4. 存续状态：永久存在/有限回合、是否可被敌方清除
5. 克制与被克制：被哪种棋子 counter，克制哪种玩法

核心设计原则（你必须遵守）：

- 静态棋子：**不能移动，但必须功能性极强**，是对局运营核心
- 本体棋子：**可移动，但单兵战力有限**，必须依赖静态棋子配合，避免本体单挑碾压所有棋子

验收标准：7个棋子功能完全不重叠，各司其职，缺一不可，没有废棋、没有超模棋。

## 阶段四：设计本体技能与天赋体系（第四步）

这套系统决定游戏的流派多样性，避免对局同质化。

你需要分步设计：

1. **天赋（被动）**：全局常驻效果，整局对局生效，定义玩家核心流派（强攻、续航、铺场、控场）。每位玩家只能选择一个常驻天赋。
2. **技能（主动）**：消耗资源释放、有冷却回合、有明确伤害/辅助效果。
3. **制衡设计**：强势天赋必有短板，例如铺场流输出低，强攻流身板脆，续航流占地慢。

验收标准：不同天赋选择，会彻底改变玩家的对局思路、棋子搭配、资源取舍。

## 阶段五：补全制衡、反滚雪球与胜负边界（第五步，最关键）

绝大多数原创棋类废掉的原因：滚雪球无解、劣势无法翻盘、单一最优解。本阶段专门解决平衡性。

你需要自主设计三类规则：

1. **劣势保护机制**：HP更低、占地更少的玩家，获得额外资源、额外buff、特殊反制技能
2. **克制链闭环**：运营铺场 < 速攻爆发 < 控场苟活 < 运营铺场，形成三角克制
3. **对局终止兜底**：最大回合数平局判定、平局胜负裁决规则（占地多/剩余资源多获胜）

验收标准：优势方无法无脑碾压，劣势方存在明确翻盘手段，没有无敌流派。

## 阶段六：自测对局迭代（最后一步）

规则写完不是终点，必须**自我双人模拟对局**：

1. 模拟3局以上对局，记录所有BUG：规则冲突、无解套路、废棋子、资源溢出
2. 每发现一个问题，只微调数值、不改动底层框架
3. 最终实现：新手有简单玩法，老手有博弈深度

## 整体执行铁律（务必遵守）

\1. **绝不跳步**：必须按顺序做完框架→资源→棋子→技能→平衡→测试

\2. **只补全不新增创意**：不要额外加新棋子、新机制，先把现有框架做成熟

\3. **所有效果必须数值化**：拒绝“加移速、加增益”这种模糊描述，全部量化
